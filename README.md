# studyplan

学习计划生成库（纯内存、无外部依赖）。由上层直接调用：调用方提供课程目录、
员工当前熟练度、岗位目标和已完成课程，库在固定培训时长预算内生成整体最划算
的学习计划，优先补上最严重的岗位技能缺口。

## 规划规则

- 技能缺口 = 岗位目标 - 当前熟练度（均为 1~5 级），仅考虑正缺口；技能优先级
  按初始缺口从大到小排列，缺口相同按技能编号字典序，生成过程中不变。
- 每门未完成课程使其每个技能标签提升 1 级，可累计，上限 5 级；每项技能的
  有效增益最多等于其初始缺口。
- 已完成课程不再安排、不再加技能，但可直接满足先修条件（不追溯它自己的先修）。
- 计划自动纳入所选课程所需的全部未完成先修课，按先修在前的顺序输出；共享
  课程只出现一次、计时一次、贡献一次。
- 在所有不超预算的合法计划中，按技能优先级排列的有效增益向量字典序最大者
  胜出；增益相同选总分钟数最少者；仍相同则任选其一。
- 预算不足以安排任何有价值的学习时返回空计划。

## 使用

```go
import "studyplan"

plan := studyplan.Generate(studyplan.Input{
    Catalog: []studyplan.Course{
        {ID: "go-basic", Minutes: 60, Skills: []string{"go"}},
        {ID: "go-adv", Minutes: 90, Skills: []string{"go", "perf"},
            Prereqs: []string{"go-basic"}},
    },
    Current:       map[string]int{"go": 1, "perf": 2},
    Target:        map[string]int{"go": 3, "perf": 3},
    Completed:     []string{"sql-basic"},
    BudgetMinutes: 180,
})
// plan.Courses      按先修在前的课程 ID 顺序
// plan.TotalMinutes 计划总分钟数（不超预算）
// plan.Gains        按优先级排列的每项技能有效增益
```

## 说明

- 输入约定：课程编号唯一、分钟数为正整数、先修引用完整且无环（由调用方保证）。
- 搜索为精确分支限界，最坏复杂度随未完成课程数指数增长，适用于单员工
  规划常见的目录规模。

## 测试

```sh
go test ./...
```

覆盖：共享先修使局部最便宜方案不再最优、已完成课程截断先修追溯、预算不足
返回空计划、增益受缺口封顶、分钟数平局决胜、优先级字典序、先修链完整性与
输出顺序、5 级上限、无缺口返回空计划。
